### 关键约定（供后续参考）
- 文件结构：`css/{tokens,base,layout}.css`、`js/{store,render,main,export}.js`
- data-* 钩子：`data-action` / `data-chapter` / `data-field`，不用 id
- 三层红线：store 不碰 DOM、render 只 return 字符串、只有 store 碰 localStorage
- 9 章节 key：`overview/scope/stack/model/risk/plan/setup/test/notes`
- 章节 type：`kv | table | text | list`
- 主题：`:root` + `[data-theme="dark"]`，JS 只改 `documentElement.dataset.theme`
